# Jinja2 기능 대시보드

- 주소: `/dashboard`. 기존 공통 계정 메뉴의 **기능 대시보드**로 진입한다.
- 회원·인증 / 공연장 / 공연·회차 / 좌석 / 예매 / 결제 화면을 도메인별로 연결한다.
- 상세 조회는 실제 ID로 이동하거나 공연 목록에서 회차·좌석을 선택한다. `/reservations`는 좌석 선택 정보가 없으면 선택 안내만 표시한다.
- 결제 확인에는 **예매 ID**를 사용한다. 토스 성공·실패 콜백에는 직접 링크하지 않는다.
- 관리자 전체 예매·결제 조회는 API 미연결을 명시한다. 임의 데이터나 구매자 API로 전체 조회를 대신하지 않는다.
- 대시보드는 공개 안내 화면이다. 관리 링크 노출은 권한 부여가 아니며, 각 기존 화면과 백엔드가 권한을 검사한다.
- 업무 API·엔티티·저장소·DB·공통 미들웨어는 수정하지 않는다. 화면의 API/필드 매칭은 `FRONTEND_API_MAPPING_KO.md`를 참고한다.

## 확인

Jinja 템플릿 파싱, 대시보드·정적 파일 HTTP 200, 상세 링크의 경로 허용 목록·양수 ID·64비트 상한 검증을 확인했다. Claude 정적 검토 후 ID 설명과 검증 안내를 보완했다. 브라우저 도구 연결 오류로 실제 시각 검수는 미완료다. 로컬 미리보기는 `/dashboard`에서 제공하며, 배포·실제 결제 검증과 구분한다.
